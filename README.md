# Bkomik Plc. website

Static website for Bkomik Plc. (Create. Inspire. Impact.)

- `index.html` is the all-in-one entry page. It holds every page, so links work even where other files cannot load.
- The other `.html` files, `style.css` and the images are the separate pages, for hosting or editing one page at a time.

Open `index.html` in a browser to view the site.
