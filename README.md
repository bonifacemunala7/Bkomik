# Bkomik Plc. website

Static website for Bkomik Plc. (Create. Inspire. Impact.)

## Files
- `index.html` is the main entry page. It holds every page inside it (styles, logo and photo included), so links work even in viewers that cannot load other files. It also has the language dropdown (English, Hindi, Chinese, Japanese, Arabic, French, Spanish, German) and a "More languages" button (Google Translate).
- The other `.html` files, `style.css` and the images are the separate pages, for hosting or editing one page at a time.

## Status
- Translated: all pages except Privacy and Terms (still English).
- Privacy and Terms are sample text and need a lawyer's review.
- Email, phone and dashboard figures are sample details.
